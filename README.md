# Парсер документации Python и статусов PEP

Проект представляет собой набор парсеров для сбора информации с сайтов документации Python и сайта PEP. Парсеры умеют:

- Извлекать список нововведений из раздела *What’s New*.
- Получать список версий Python и их статусов (из боковой панели).
- Скачивать ZIP-архив с документацией (например, HTML, PDF или EPUB).
- Собирать статистику по документам PEP: подсчитывать количество документов в каждом статусе и выявлять несовпадения статусов в общем списке и на отдельных страницах.

Проект написан на Python с использованием `requests_cache`, `BeautifulSoup4`, `tqdm` и `prettytable`. Логирование настроено с ротацией, а все исключения корректно обрабатываются и записываются в лог.

📖 Использование
Парсер запускается через командную строку из папки src:

bash
cd src
python main.py <режим> [опции]
Режимы (обязательный позиционный аргумент)
Режим	Описание
whats-new	Собирает ссылки, заголовки и авторов статей из раздела What’s New в документации Python.
latest-versions	Получает список всех версий Python со ссылками и статусами (из боковой панели).
download	Скачивает ZIP-архив с документацией Python (любой доступный формат).
pep	Собирает статусы всех PEP, сравнивает их с ожидаемыми, подсчитывает количество документов в каждом статусе и выводит итоговую таблицу.
Опции (необязательные)
Опция	Длинная опция	Описание
-c	--clear-cache	Очищает кеш HTTP-запросов перед выполнением.
-o	--output	Управляет выводом результатов. Доступные значения: pretty (красивая таблица в терминале) или file (сохранение в CSV). Если не указана, результаты выводятся в терминал построчно.
📌 Примеры команд
1. Вывод списка нововведений в виде таблицы
bash
python main.py whats-new -o pretty
2. Список версий Python с сохранением в CSV
bash
python main.py latest-versions -o file
3. Скачать архив с документацией
bash
python main.py download
Архив сохранится в папку downloads/.

4. Собрать статистику по PEP и сохранить в CSV
bash
python main.py pep -o file
Результат появится в results/pep_<дата-время>.csv.

5. Очистить кеш перед запуском
bash
python main.py pep -c -o pretty

⚙️ Особенности реализации
Кеширование запросов – используется requests_cache, что ускоряет повторные запуски.

Логирование – настроено в файл и в консоль с ротацией (максимум 5 файлов по 1 МБ).

Обработка ошибок – все сетевые ошибки и ошибки поиска тегов перехватываются и логируются, при этом парсер продолжает работу (кроме критических сбоев).

Прогресс-бар – для длительных операций используется tqdm.

Сравнение статусов PEP – парсер загружает JSON-список всех PEP, затем для каждого документа открывает страницу и извлекает актуальный статус. Несовпадения с ожидаемыми статусами записываются в лог (уровень INFO), а ошибки парсинга – в ERROR.
